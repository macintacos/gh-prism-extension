gh-prism is installed

gh-prism splits a pull request's changed files into sections. It runs on GitHub's new Files changed page, whose URL ends in /pull/<number>/changes, and on commit pages. GitHub's classic Files changed page, whose URL ends in /files, looks the same with or without gh-prism.

A pull request shows the new page only when both of these hold:

  1. You're signed in to GitHub in this Chrome profile

    Signed out, GitHub always shows the classic page, even for a public pull request, so gh-prism has nothing to change.

  2. GitHub's "New Files Changed Experience" is on

    It's on by default. If you turned it off, GitHub shows you the classic page. To turn it back on, click your profile picture in the upper-right corner of any GitHub page, click Feature preview, choose New Files Changed Experience, and click Enable.

    GitHub Docs: Exploring early access releases with feature preview. GitHub changelog: Improved pull request "Files changed" page on by default.

Reload any GitHub tab that was open before you installed gh-prism. Tabs opened before the install don't run it.
