gh-prism is installed

gh-prism splits a pull request's changed files into sections. It runs on GitHub's new Files changed page, whose URL ends in /pull/<number>/changes, and on commit pages. A pull request shows the new page only when both of these hold:

  • You're signed in to GitHub in this Chrome profile

    Signed out, GitHub always shows the classic Files changed page, whose URL ends in /files, even for a public pull request.

  • GitHub's New Files Changed Experience preview is on

    It's on by default. If you turned it off, GitHub shows you the classic page. To turn it back on:

    1. Click your profile picture in the upper-right corner of any GitHub page.
    2. Click Feature preview.
    3. Choose New Files Changed Experience.
    4. Click Enable.

    GitHub Docs: Exploring early access releases with feature preview. GitHub changelog: Improved pull request "Files changed" page on by default.

On the classic page, gh-prism shows a notice that says which of these to fix. Dismiss it, and Why is gh-prism off? in the page's toolbar brings it back.

Reload any GitHub tab that was open before you installed gh-prism. Tabs opened before the install don't run it.
