# Editing `CONTRIBUTING.md`

*Audience: coding agents and contributors editing gh-prism's contributor guide.*

[`CONTRIBUTING.md`](../../../CONTRIBUTING.md) is the short front door for contributors:
setup, everyday tasks, where tests live, and links onward. Keep it minimal. It orients a
new contributor, then points at `README.md`, the `docs/` pages, and `AGENTS.md` for depth.
Never let it grow into a second README.

When to edit it:

- A setup step or an everyday task changes. Update
  [`docs/DEVELOPMENT.md`](../../DEVELOPMENT.md) in the same change.
- The test layout moves.
- A doc it links to is added, renamed, or removed.

Maintenance: `CONTRIBUTING.md` is a node on the documentation map. Adding, removing, or
renaming it, or this pointer, follows the maintenance rule in
[`documentation-rules.md`](../documentation-rules.md).
