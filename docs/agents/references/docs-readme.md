# Editing `docs/README.md`

*Audience: coding agents and contributors editing the router for `docs/`.*

[`docs/README.md`](../../README.md) maps what a reader wants to do to the page that
answers it, across the `docs/` pages, `CONTEXT.md`, and `agents/`.

When to edit it:

- A page under `docs/` is added, renamed, or removed.
- A page's scope changes enough that its entry no longer describes it.

Keep each entry one line on the reader's goal plus a link. The page itself holds the
detail.

Maintenance: this doc is a node on the documentation map. If you rename or restructure it,
update [`documentation-rules.md`](../documentation-rules.md) per its maintenance rule.
