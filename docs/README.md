# gh-prism docs

*Audience: anyone looking for the right page about how gh-prism works or how to develop
it.*

Pick the page that matches what you want to do:

- **Learn how gh-prism works before changing it:** read
  [`ARCHITECTURE.md`](ARCHITECTURE.md).
- **Build, test, or benchmark gh-prism locally:** read
  [`DEVELOPMENT.md`](DEVELOPMENT.md).
- **Look up a term such as visit, intent, or section:** read
  [`CONTEXT.md`](../CONTEXT.md).
- **Find the rules a code area follows:** read the rule files in [`agents/`](agents/).

Adding a new rule? See
[`agents/references/agent-rules.md`](agents/references/agent-rules.md).
